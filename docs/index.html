Is this opportunity worth your weekend?

Paste a hackathon, bounty or grant page. Bounty Lens extracts deadline, prizes, eligibility and deliverables, flags anything that needs your money or a student ID, and estimates dollars per hour. It runs on Gemini Nano on your device first, so the page never leaves your computer. If your device can't run it, it falls back to Gemini in the cloud through Firebase AI Logic.

My pipeline

How it works

  1. Local scan first. Regex rules (from Firebase Remote Config) flag deposits, trading, KYC, students-only, in-person and country limits before any model runs.
  2. Hybrid inference. Firebase AI Logic in PREFER_ON_DEVICE mode runs Gemini Nano through Chrome's built-in Prompt API with a JSON-schema constraint, and switches to cloud Gemini only if the device can't.
  3. Strict merge. Local rules can only make a verdict stricter, and past deadlines are always SKIP.
  4. Rank. Expected value per hour = prize per winner × your win chance ÷ effort, with GO items first.
  5. Sync. Briefs save to Firestore under an anonymous Firebase Auth user, and App Check protects the AI endpoint.
Built with Firebase AI Logic (hybrid inference), App Check, Auth, Firestore and Remote Config. Source
